# 任务：不训练，只靠修改权重，让一个神经网络变得更准

你是这个实验的执行者，请自己完成全部工作，直到交出结果，不要把步骤交还给用户来做。
本文件夹里的东西就是你需要的全部材料。

## 背景：网络在做什么

- **任务**：语音的逐帧音素分类。音频来自 LibriSpeech 朗读英语。每 10ms 取一帧（25ms 窗），每帧提取 28 维 MFCC 特征。
- **归一化**：每一句话内部，28 维中的每一维各自减去这句话里的均值、除以标准差（倒谱归一化）。
- **输入**：要分类第 t 帧时，取它前后各 40 帧，共 81 帧 × 28 维 = 2268 个数。展平顺序是"时间在外、特征在内"，即输入下标 i = t*28 + f。t = 0..80，t = 40 是被分类的中心帧，t < 40 是过去，t > 40 是未来；f = 0..27 是 MFCC 的维度。窗口超出句子首尾的部分补 0，不会跨到别的句子。
- **输出**：42 个 logits，下标对应的音素见 `tools.PHONEMES`。实际出现的标签只有 0–39；40（[SOS]）和 41（[EOS]）从来不会作为标签出现。0 是静音 [SIL]。
- **网络**：
  ```
  h1 = relu(x @ W1 + b1)      W1: 2268 x 1024
  h2 = relu(h1 @ W2 + b2)     W2: 1024 x 1024
  logits = h2 @ W3 + b3       W3: 1024 x 42
  ```
  没有 BatchNorm，没有 Dropout。共 3,416,106 个参数。
- **它是怎么训练出来的**：AdamW（lr 1e-3，weight decay 0.01，batch 1024），训练数据是 12000 句话（15,203,231 帧）。训练到第 9,400 步（看过 9,625,600 帧，约 0.63 个 epoch）时准确率第一次达到约 70%，就停下了。也就是说，它**训练得不充分**。

## 材料

- `subject_net.npz`：要修改的网络（W1, b1, W2, b2, W3, b3）。
- `dev_A_part1.npz`、`dev_A_part2.npz`：**练习集 A**，1351 句话，947,349 帧，带标签。
- `tools.py`：加载数据、构造输入窗口、前向传播、评估、保存。用法见文件开头的说明。
- 原网络在 A 上的准确率是 0.6980。

另外还有一个**考试集 B**：1352 句话，和 A 来自同一个分布（不同的句子）。你拿不到它。你交卷后，实验者会在 B 上评估一次，那就是最终成绩。

## 目标

修改 `subject_net.npz` 的权重，让网络在考试集 B 上的准确率尽可能高。

## 规则

**禁止：**
1. 任何形式的训练：反向传播、autograd（`requires_grad`、`backward`）、优化器、梯度。
2. 把"让 A 上的损失或错误最小"当作目标直接去求解权重。这包括迭代拟合，也包括闭式解（例如用最小二乘、逻辑回归、LDA 直接解出一个权重矩阵）和自动搜索（由程序反复试各种权重、按效果挑选，例如随机搜索、网格搜索、坐标下降）。
3. 联网。
4. 读取本文件夹以外的任何东西：不要搜索或查看过去的对话、记忆、项目文档，也不要请求访问其他文件夹。实验需要的信息都在本文件夹里，额外信息会破坏实验。

**允许：**
- 读权重，做任何分析。
- 用 `forward` 在 A 上跑任何网络（原网络或修改后的），看激活、看原网络的混淆矩阵和错误，不计次数。
- 用数据的统计量（均值、方向、频率、相关等）来理解网络和构造修改。但每一处修改都要能用一句话说出它在修什么、为什么这样改会有用。

**评估预算：0 次。你不能评估任何修改后的网络：不能调用 `evaluate`，也不能自己用 A 的标签去算修改后网络的准确率或损失（看原网络的错误不受限制）。只能根据分析和推理，一次写出最终修改。**
