# 窗口 1C（原版权重 net_k3.npz）的最终回答

> 由用户从对话中复制保存。

我先用 Python 把权重拆开来分析：看输入维度的结构、W1 行之间的相关性和空间规律，以及 W3 里类别之间的关系。

## 观察

**1. 输入是 81 × 28 的网格，并且按 `i = 28·t + c` 排列**（来自数值）
- 把 W1 每一行的范数当作长度 2268 的序列来看，自相关在滞后 28、56、84 处最高（0.99、0.97、0.93）；FFT 主峰在 k=81，对应周期 28。
- 同一列里相邻行的权重向量很像，余弦相似度 0.8–0.9。同一行里相邻列的相似度只有 ±0.1 左右。所以 81 这个维度是平滑轴，28 这个维度是一组彼此基本去相关的特征。
- 光看形状，2268 有很多种分解（36×63、42×54、12×189 等）。确定是 81×28，靠的是这条周期证据。

**2. 中间那一帧最重要**（来自数值）
- 范数图在第 40–41 行达到峰值：第 27 列为 13.3，第 0 列为 10.9。往两边对称衰减，到边缘降到约 1.2–2.0。
- 权重最小的一行范数也有约 0.93，没有完全没被用到的输入。

**3. 28 列各自的特点**（来自数值）
- 第 0 列和第 27 列最重要。按类别区分度算，两者都是 6.8，第 2 列 3.3、第 1 列 2.7，之后单调下降，到第 13–25 列只剩约 0.6。
- 时间上的平滑程度也随列号下降：第 0 列为 0.91，第 23 列为 0.57。
- 第 26 列很特别：在时间上几乎是白噪声（滞后 1 的相似度 0.13），和其他任何列、任何时滞的相关都在 0.01 左右，各行范数都差不多（约 1.7），也没有中心峰。
- 我检验了"某些列是另一些列的差分（delta）"这个可能：交叉时滞相关的奇对称部分不超过 0.05，所以排除了。

**4. 输出层**（来自数值）
- 类别 0 的偏置 b3=1.25，远高于其他类（第二名 0.53）。输入取均值（x=0）时，网络也预测类别 0。
- 类别 40 和 41 的 W3 列余弦相似度达 0.81，而且 78% 的权重是负的。在平滑噪声输入上，它们的平均 logit 约为 −17.8，其他类在 −1 到 −6 之间。用激活最大化也没法把它们的概率推过 0.04。这正是"训练集里几乎没出现过的类"会留下的痕迹。

## 推理

**类别：先假设成音素，再检验**
- 把 1–39 号类别按字母顺序对应到 ARPAbet 的 39 个音素（AA AE AH … Z ZH），W3 中最相似的类别对几乎全部符合语音学：
  - AA 和 AO、AW、AY；B 和 P、V、M；CH 和 SH、JH、T；D 和 T、N、Z
  - ER 和 R；G 和 K；N 和 NG、M、D；S 和 Z、SH；TH 和 F、DH；UH 和 UW；ZH 和 SH、JH
- **定量检验**：用一组语音学特征（发音方式、部位、清浊）构造音素之间的相似度，和 W3 的余弦矩阵算相关，得到 r=0.45。5000 次随机排列的最大值只有 0.17，z 值为 12.8。
- 把整个映射错开一位，r 就掉到约 0。换成 TIMIT-39 的字母顺序，最好也只有 0.25。
- **稀有度也对得上**：W3 中最受压制的真实类别依次是 ZH、OY、UH，它们恰好是英语里最少见的几个音素。
- **类别 0 是静音**：它在能量列（第 27 列）的梯度为 −7.1，是所有类中最低的。

**输入：倒谱特征 + 能量**
- 用平滑噪声做输入，求每个类别的平均梯度模板（来自数值）：
  - 第 0 列对擦音很负：S −9.0、SH −7.5、CH −6.9、F −5.6。对鼻音和后元音为正：M +5.8、NG +4.5、OW +3.8。
    - 这是 c1（频谱倾斜）的典型表现。
    - 它不可能是能量：如果是能量，S 不会比静音还低。
  - 第 27 列在元音上为正，在静音（−7.1）、P/K/B/T/G 的闭塞段、以及弱擦音 F/TH 上为负。咝擦音 S/SH/Z/ZH 偏高，弱擦音 F/TH 偏低。
    - 这是对数能量（或 c0）的表现。
  - 第 2 列把前元音、硬腭音（Y、IY、ZH、JH）和后元音（AA、AO、OW）分开，和 F2 有关。
- 列与列之间基本去相关，重要性和平滑度都随列号单调下降。这符合按阶数排列的倒谱（DCT 后的特征）。
- 已排除的候选：
  - 对数梅尔滤波器组：相邻频带高度相关，会让相邻列的权重很像，与观察不符。
  - 图像：图像的两个轴都该平滑。
  - 整段序列分类（例如 EEG 或动作识别）：不会出现以中心帧为峰的对称结构。
  - 传感器式的人体活动识别：同理。

**时间方向和帧率**
- 塞音 P、T、K 的能量模板是：中心帧附近为强负值（闭塞），后面约 4–6 帧转为正值（除阻、后接元音）。这说明行号越大，时间越晚。
- 类别模板的半高宽在 3–10 帧之间。如果帧移是 10 ms，对应 30–100 ms，正好是音素时长的量级。不过这一点只是"一致"，不算强证据。

## 答案

- **输入数据**：英语语音的逐帧声学特征（MFCC 类）。
- **输入结构**：
  - 81 帧 × 每帧 28 维，按时间优先排列：`x[28·t + c]`，其中 t=0…80。
  - 第 40 帧是要被分类的那一帧，前后各带 40 帧上下文。按 10 ms 帧移算，大约是 ±0.4 s。
  - 每帧的 28 维：
    - 第 0–25 列：按阶数递增的倒谱系数，很可能是 c1…c26。高阶的几列（约 13–25 列）信息很少。
    - 第 26 列：近似白噪声、几乎不含信息的辅助通道，具体是什么无法确定。
    - 第 27 列：对数能量或 c0。
- **任务**：逐帧音素分类。也就是混合式 DNN-HMM 语音识别里的声学模型，或者在强制对齐标签上训练的帧级音素识别器。损失是帧级交叉熵。
- **42 个类别**：
  - 0 = 静音（SIL）
  - 1–39 = 去掉重音标记的 CMU/ARPAbet 39 个音素，按字母排序：
    - 1–10：AA AE AH AO AW AY B CH D DH
    - 11–20：EH ER EY F G HH IH IY JH K
    - 21–30：L M N NG OW OY P R S SH
    - 31–39：T TH UH UW V W Y Z ZH
  - 40、41 = 两个在训练数据里几乎不出现的非音素标签。可能是 SPN/NSN（有声噪音、非语音噪音）这类"未知或噪音"标签，也可能是填充标签。
  - 训练语料可能是 LibriSpeech、WSJ 一类使用 CMU 词典的英语语料，这一点是猜测。

## 什么证据会让我改变结论

- **类别映射**：如果拿到真实输入后发现类别 0 对应的是高能量的帧，或者 W3 的相似度结构用另一种标签顺序（例如非英语音素集）能拟合得明显更好，我会推翻这套映射。
- **特征解释**：如果第 13 列以后的特征被证实是另一类特征（例如音高、过零率），而不是更高阶的倒谱，我会修改"28 维 = 倒谱 + 能量"这个解释。第 13、14 列之间有 0.55 的异常相关，这是我目前没能解释的一处。
