## 冻结的修改规则（不使用 LLM）

所有规则在删除权重之后都做同样的 b2 均值补偿：用 A 上随机 40000 帧（种子 0）的无标签 h1 均值，令 `b2 += (原 h1 均值 − 新 h1 均值) @ W2`。

- **H1 行范数规则**：把 W1 里"平均行范数最小"的 18 个时间偏移置 0。数字 18 是从 2A 的修改继承来的，不是独立选出的超参数。
- **H2 最小 η² 规则**：在 A 上对每个特征维（中心帧）计算 η² = 类间平方和 / 总平方和，把 η² 最小的那一维在全部 81 帧上的 W1 行置 0。
- **H3 组合**：先做 H1，再在它的结果上做 H2（补偿基于 H1 之后的网络重新计算）。
- **H2+cal**：先做 H2，再对 b3 做一次 2B 的先验校准：`b3[c] += log(π_c / q̄_c)`（c = 0…39），其中 π 是 A 的类别频率，q̄ 是 H2 之后的网络在 A 上的平均 softmax；b3[40:42] 设为 −20。

网络 1（原被试网络）的已有版本照原样评估，不做任何修改：`ed2A`、`ed2A_E12`、`ed2B`、`ed2B_E1`、`base_magprune22`、`combo_2A_E12_plus_f26`。
