## 分析 1：位移的径向/切向分解（脚本 `代码/displacement.py`）

### 设置
- **远端权重**：W1 中 |Δt| ∈ 30…38 的全部行（18 个偏移 × 28 个特征 × 1,024），拼成一个向量 w0（被试网络）。网络 N 的对应向量记为 w，位移 d = w − w0。
- **分解**：
  - 径向分量 r = (w0·d)/|w0|，负值表示朝 0 移动；
  - 切向分量 t = sqrt(|d|² − r²)；
  - 都换算成"每个权重"的量：除以 √(元素个数)。
- **weight decay 的份额**：AdamW 解耦衰减在 T 步、lr η、wd 0.01 下，把权重乘以 (1 − 0.01η)^T。由此算出的径向位移作为参照（lr 1e-4、10,000 步时约为 −1% × |w0|）。
- **对照**：
  - 中心附近权重 |Δt| ≤ 10，做同样的分解；
  - 行级分析：每一行（1,024 维）单独算径向分量，报告朝 0 移动的行所占比例。
- **网络**：
  - lr 1e-4 长训练的 5 个检查点（第 2,000–10,000 步）；
  - lr 1e-4 同状态 +2,000；
  - lr 1e-3 继续训练 +2,000、+4,000。
- **随机游走的参照**：Adam 每步的更新约为 η·m̂/√v̂。若某权重的梯度是零均值噪声，动量只是把噪声平滑，累加起来仍约等于 η 乘以 T 个单位方差随机数之和，位移 RMS 约为 η√T。这是纯噪声时的预期值；若梯度有回拉，实际位移会更小。

### 预测
1. lr 1e-4、第 10,000 步、远端权重：
   - 径向分量为负（朝 0），每个权重约 −0.002 到 −0.004，至少是 weight decay 份额（约 −0.0004）的 3 倍；
   - 切向分量每个权重约 0.010 到 0.011，至少是径向分量绝对值的 2 倍。
   - 这一条几乎由已知的范数和位移推出，主要是把评审的粗算正式算一遍。
2. lr 1e-4 长训练中，远端位移 RMS 随步数近似按 √T 增长：第 10,000 步与第 2,000 步之比在 1.8 到 2.7 之间（纯随机游走是 √5 ≈ 2.24，匀速漂移是 5），量级与 η√T 相当（第 10,000 步 η√T = 0.010）。
3. 行级：lr 1e-4、第 10,000 步，朝 0 移动的远端行占 60% 以上。
4. lr 1e-3 继续训练：
   - 位移 RMS 低于 η√T 的上界（+2,000 步时上界是 0.045）。如果真按这个上界随机游走，范数会涨约 50%，而实测只涨了 6%；
   - 径向分量同样朝 0。
   - 把握较小。

### 判断规则（决定论文措辞）
看 lr 1e-4、第 10,000 步的远端权重：
- 径向 < 0，|径向| ≥ 3 × weight decay 份额，且 |径向| < 0.5 × 切向：写成"有一个弱的、指向 0 的拉力，但被随机运动主导"（按第四版评审建议的措辞）。
- |径向| ≥ 0.5 × 切向：写成"有明显的拉力"，并相应修改"累积版"的说法。
- |径向| < 3 × weight decay 份额：写成"除了 weight decay 之外检测不到拉力"。

另一条：位移比（第 10,000 步 / 第 2,000 步）在 [1.8, 2.7] 之间，写成"位移按 √T 增长，和随机游走一致"；≥ 3.5 写成"更像漂移"；其他情况照实描述。

## 分析 2：训练集上的 H1（脚本 `代码/train_set_h1.py`）

### 设置
- **训练顺序重建**：
  - 被试网络和 lr 1e-4 长训练用的是同一种方式生成的小批次顺序：`torch.manual_seed(0)` → 建网络（初始化消耗随机数）→ `torch.randperm(15,203,231)`。所以两者的帧顺序完全相同。
  - 被试网络看过 perm 的前 9,400 × 1,024 = 9,625,600 帧，各一次；
  - 第 10,000 步的检查点又从头看了 perm 的前 10,240,000 帧。
- **重建核对**：用重建的顺序从头重跑被试训练的前 200 步，核对第 200 步的 loss（1.518）和 monA（0.5399）与 `日志/train_log.txt` 一致。不一致就停下来报告，不做后面的分析。
- **两类训练帧**（三个 train chunk 按 0、1、2 的顺序拼接，与训练时相同）：
  - **seen**：网络训练中看过的帧。被试是 perm[:9,625,600]；第 10,000 步检查点是 perm[:10,240,000]，其中前 9,625,600 帧看过两次。
  - **unseen**：训练集里从没看过的帧，即上面范围之外的部分。它们来自同样的句子和说话人，但这些帧本身没参与过梯度计算。
  - 每类用 numpy `default_rng(0)` 抽 1,000,000 帧（不放回）。
- **网络**：被试、H1(被试)、H1 不补偿(被试)；第 10,000 步检查点、H1(它)、H1 不补偿(它)。H1 与 `heur.py` 冻结的规则完全相同。
- **指标**：准确率和平均交叉熵（自然对数）。另外在 B、C 上补算这 6 个网络的平均交叉熵，以便同一指标下比较（准确率之前已报告，不重算）。
- **不确定性**：按句子 bootstrap 2,000 次（rng 种子 0）。seen 和 unseen 的帧来自同一批句子，所以在同一次重抽样里同时算两者，得到差值 g_seen − g_unseen 的区间。

### 两种解释的预测
- **噪声解释**（远端权重是对训练损失也有害、但梯度信号太弱推不动的噪声）：H1 在 seen 训练帧上也提升准确率、降低损失，幅度与 unseen 帧相近。
- **过拟合解释**（远端权重拟合了训练数据）：H1 在 seen 帧上无益或有害，在 unseen 帧和测试集上有益，即 g_seen 明显小于 g_unseen。

### 我的预测
- 被试网络：每帧最多只看过一次，记忆效应应该很弱；被试自己在 seen 和 unseen 帧上的准确率差距小于 1 pp。
- H1(被试) 在 seen 帧上提升约 +0.3 到 +0.5 pp，区间不含 0；g_seen 与 g_unseen 之差的区间包含 0。损失同样下降。
- 第 10,000 步检查点：H1 在 seen 帧上仍为正（约 +0.1 到 +0.2 pp）。
- 把握约七成。

### 判断规则（以被试网络、带补偿的 H1、准确率为主；另外三种组合照实报告）
- **支持噪声解释**：g_seen > 0 且区间不含 0，并且 g_seen ≥ 0.5 × g_unseen。
- **支持过拟合解释**：g_seen ≤ 0 而 g_unseen > 0（区间不含 0）；或者 g_seen < 0.5 × g_unseen，且 g_seen − g_unseen 的区间不含 0。
- **其他情况**：结果不一致，照实报告。

所有网络、所有组合、所有指标都报告，不挑选。
