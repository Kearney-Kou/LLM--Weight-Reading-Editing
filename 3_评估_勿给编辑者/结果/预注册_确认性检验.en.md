# Pre-registration: confirmatory test (written at 2026-11-04 02:34 UTC, before running any confirmatory test)

Background: in the first version of the paper, the heuristic baselines, the combined edits and the feature ranking were all designed after seeing the results on B (post hoc analysis), and were all done only on B. Item 4 of the review comments asks: first freeze the rules, then validate them on new data or in new experiments. This file freezes the rules and predictions below. Whatever the results, they will be reported according to this file, and it will not be modified.

## New data and new networks

- **Test set C**: 1500 utterances drawn from `train-clean-100`. These utterances are neither among the 12000 used for training (seed 2026) nor among the abandoned 3000 (seed 11785), and are drawn at random with seed 314159. Note: the speakers of C overlap with the speakers of the training set ("seen speakers, unseen utterances"), which differs from B (the speakers of B do not overlap with the training set). The features of C are processed exactly like the other data.
- **New-seed networks**: seed 1 and seed 2. Apart from the random seed, the training setup is exactly the same as for the original subject network (`train_subject.py`), including the data, architecture, optimizer and stopping rule (stop the first time accuracy is ≥ 70% on the same 100,000-frame monitoring subset of A). Only the subject network is saved.

## Frozen editing rules (no LLM used)

After deleting weights, every rule applies the same b2 mean compensation: using the unlabelled h1 mean over 40000 random frames of A (seed 0), set `b2 += (original h1 mean − new h1 mean) @ W2`.

- **H1 row-norm rule**: set to 0 the 18 time offsets in W1 with the "smallest mean row norm". The number 18 is inherited from 2A's edit, not an independently chosen hyperparameter.
- **H2 minimum-η² rule**: on A, compute for each feature dimension (centre frame) η² = between-class sum of squares / total sum of squares, and set to 0 the W1 rows of the dimension with the smallest η² over all 81 frames.
- **H3 combination**: first apply H1, then apply H2 to its result (the compensation is recomputed based on the network after H1).
- **H2+cal**: first apply H2, then apply 2B's prior calibration once to b3: `b3[c] += log(π_c / q̄_c)` (c = 0…39), where π is the class frequency of A and q̄ is the mean softmax on A of the network after H2; b3[40:42] is set to −20.

The existing versions of network 1 (the original subject network) are evaluated as they are, without any modification: `ed2A`, `ed2A_E12`, `ed2B`, `ed2B_E1`, `base_magprune22`, `combo_2A_E12_plus_f26`.

## Predictions (written down in advance)

- **P1**: on C, `ed2A`, `ed2A_E12`, H1 and H3 of network 1 are all higher than the original network, with 95% intervals excluding 0; the difference between H1 and `ed2A_E12` is within ±0.1 percentage points.
- **P2**: on C, the point estimate of H2 of network 1 (identical to `ed2B_E1`) is ≥ 0.
- **P3**: for seed 1 and seed 2, H1 and H3 are higher than their respective original networks on both B and C, with 95% intervals excluding 0; the point estimate of H2 is ≥ 0.
- **P4**: for all seeds, H2 selects dimension 26.

## Statistical method

- Primary metric: accuracy difference (edited − original network), paired bootstrap by utterance (2000 times, seed 0), 95% interval reported.
- Supplementary: paired bootstrap by speaker (whole speakers resampled together).
- Each network is evaluated only once on each test set.
