## B1：更强的通用读权重基线

### 输入和打分（与 R1/R2 完全相同）
- 输入：`1_阶段1_读权重/net_q7.npz` 的 `W1`（2268×1024），打乱顺序 `perm = np.random.default_rng(777).permutation(2268)`（与 `reading_baseline.py` 相同；q7 第 i 行 = 原输入 perm[i]，原输入下标 = 28·t + f）。
- 主指标（与 R1/R2 相同的 `score`）：一组算"正确" = 恰好 81 行、全部来自同一个原特征、组内顺序与真实时间严格单调（正向或反向，相邻差恰为 ±1）。报告 28 组中正确的条数。
- 次要指标（新加，只作辅助说明）：
  - 纯组数：恰好 81 行且全部来自同一特征的组数（R2 报告过同一指标）；
  - 分组与真实特征的 Adjusted Rand Index（ARI）；
  - 在纯组里，组内顺序与真实时间的 |Spearman ρ| 的中位数。
- 所有方法只用 W1 的行，不用任何关于答案的信息（不用"28 条链、每条 81"以外的先验——组数 28 和每组 81 这两个数和 R2 一样作为已知输入，因为 1B 的提示里也给了 2268 和 42 两个维度，而 81×28 是 1C/1B 自己推断的；这里与 R2 保持一致）。

### 方法和参数网格（事先固定，全部报告）
相似度 S = 行余弦相似度（与 R1/R2 相同，不中心化）。

**G1：kNN 图 + 谱聚类成 28 组 + 组内 Fiedler 排序**
- kNN 图：每行连到余弦最相似的 k 行，取并集对称化；边权 = max(S, 0)。
- 谱聚类：`sklearn.cluster.SpectralClustering(n_clusters=28, affinity='precomputed', random_state=0)`，标签分配方式 ∈ {`kmeans`（n_init=10）, `cluster_qr`}。
- 组内排序：与 R2 完全相同（组内 max(S,0) 稠密子矩阵的未归一化拉普拉斯的 Fiedler 向量排序）。
- 网格：k ∈ {5, 10, 20, 40} × 分配方式 2 种 = 8 个设置。

**G2：整张图的谱排序（spectral seriation，Atkins et al. 1998 的做法）**
- 对整张图的未归一化拉普拉斯取 Fiedler 向量，把 2268 行排成一条序列，按顺序切成 28 段、每段 81 行，作为 28 条链。
- 图：稠密 max(S,0)，以及 G1 的 kNN 图 k ∈ {5, 10, 20, 40}（不连通时 Fiedler 向量退化，照实报告）。
- 网格：5 个设置。

**G3：Le Roux et al.（NeurIPS 2007）"Learning the 2-D Topology of Images" 的思路**
原文做法（已用网络核对）：像素间相关系数 ρ → 距离 D = sqrt(−log|ρ|) → k 近邻图（原文 k = 4）→ Isomap 嵌入到 2 维 → 对齐到网格。
这里把 W1 的每一行当成一个"像素"，ρ = 行与行的 Pearson 相关（行中心化后的余弦）。
- **G3a（照搬原文）**：Isomap 嵌入 2 维（sklearn `Isomap(n_neighbors=k, n_components=2, metric='precomputed')`，图不连通时由 sklearn 自动补边），再对齐到 28×81 网格：沿第 1 坐标排序切成 28 段每段 81 行，段内按第 2 坐标排序；以及把两个坐标对调的另一种朝向。k ∈ {4, 8, 16} × 朝向 2 种 = 6 个设置。
- **G3b（适配到"多条一维链"）**：同样的距离和 k 近邻图，算图上测地距离（不连通的点对设为有限测地距离最大值的 2 倍），用平均链接层次聚类分成 28 组，组内用 1 维经典 MDS（即 1 维 Isomap）在测地距离上排序。k ∈ {4, 8, 16} = 3 个设置。

合计 22 个设置。运行时间一并报告。

### 预测
- G1：在小 k（5 或 10）下能恢复大部分特征链，**至少一个设置 ≥ 20/28**；k = 40 时明显变差。理由：1B 观察到每行最相似的几行是同一特征的相邻时刻，小 k 的 kNN 图几乎就是 28 条互不相连的链，谱聚类擅长切开近乎不连通的分量。不确定的地方是组内 Fiedler 排序在远端"噪声底"的行上会不会排错。
- G2：所有设置 ≤ 2/28。理由：一条全局序列无法同时表达 28 条互不相关的链。
- G3a：所有设置 ≤ 5/28（2 维网格假设不适合"特征之间没有顺序"的布局）。
- G3b：小 k 下与 G1 相近（≥ 15/28）。
- 论文措辞的决定规则（事先写定）：
  - 如果任何 G1 或 G3b 设置 ≥ 20/28：说明"通用的局部图方法也能做到"，摘要和 Discussion 里"LLM 的贡献是选对了方法"要收窄为：LLM 选的是一类标准的局部近邻图方法，而失败的只是"全局"聚类（R2）；LLM 的具体贡献降为"识别出链状结构、给出可检验的解释"，不是找到了一般人想不到的方法。同时如实报告结果对 k 的敏感程度。
  - 如果所有通用方法都 ≤ 5/28：加强原说法，即通用方法（包括专为恢复像素拓扑设计的 Le Roux 方法）都失败，1B 的"两强两弱近邻"观察确实是关键。
  - 介于两者之间：照实描述，说明哪些设置部分成功。

## B2：噪声假说的检验（H1 用在继续训练过的网络上）

### 设置
- 网络（都在 `3_评估_勿给编辑者/网络/`，不修改）：
  - `reference_samestate_lr1e-4_plus2000steps.npz`（同一 AdamW 状态，lr 1e-4，+2000 步）
  - `reference_lr1e-4_plus2000steps.npz`（新 AdamW 状态，lr 1e-4，+2000 步）
  - `reference_plus2000steps.npz`、`reference_plus4000steps.npz`（同一状态，lr 1e-3，+2000/+4000 步，对照）
  - 另外把被试网络 `subject_net.npz` 用同一脚本重算一遍，作为数值一致性检查（应复现已报告的 B +0.40/+0.44、C +0.39/+0.46）。
- 规则：`heur.py` 里冻结的 H1（每个网络按它自己的行范数选最低的 18 个偏移），两种版本：带 b2 补偿（`H1(w)`）和不带补偿（`zero_comp(w, rownorm_mask(w)[0], comp=False)`）。补偿用的 40,000 帧 A 与原来相同（seed 0）。
- 评估：与 `confirm_eval.py` / `summarize_confirm.py` 相同。在 B 和 C 上算每句正确帧数；差值 = H1(网络) − 网络本身（不是相对被试）；按句子 bootstrap 和按说话人 bootstrap 各 2000 次，rng 种子 0，95% 百分位区间。
- 行范数剖面：与 Fig 1 相同（W1 reshape 成 81×28×1024，对 1024 求范数，再对 28 个特征求平均），五个网络叠在一张图上。"远端底"的数值指标 = |Δt| ∈ 30…38 的平均行范数（2A 清零的区域），另报 |Δt| ≥ 26 的中位数（Fig 1 脚本里用过的指标）。
- 同时报告每个网络上 H1 选中的偏移。

### 噪声假说有两种版本，预测不同
1. **平衡版（Mandt et al. 式）**：远端权重在一个以 0 附近为中心的平稳分布里抖动，抖动幅度随学习率增大。降低学习率后，分布收缩 → 远端底下降 → H1 能删掉的噪声变少 → **H1 的提升明显变小**。lr 1e-3 继续训练：底不变，H1 提升不变。（这是任务说明里写的预测。）
2. **累积随机游走版**：远端权重没有恢复力（AdamW 的 weight decay 是 0.01×lr，2000 步 lr 1e-4 只缩小约 0.2%），噪声是 9,400 步里积累下来的，降低学习率只是让它不再继续增长，不会把它消掉 → 远端底基本不变，**H1 提升基本不变**。lr 1e-3 继续训练：底继续上升（随机游走幅度 ∝ √步数），H1 提升不变或变大。
3. **非噪声的解释**（远端输入本身起负作用，删掉相当于正则化或缩短上下文窗口）：H1 提升在所有网络上都差不多，与远端底的高低无关。

### 事先写定的判断规则
记 g(N) = H1 在网络 N 上的提升（pp），g0 = 同一测试集、同一版本（带/不带补偿）下被试网络的提升。
- **支持平衡版**：两个 lr 1e-4 网络在 B 和 C 上、两种版本下的 g 都 ≤ 0.5·g0；同时两个 lr 1e-3 网络的 g 都 ≥ 0.5·g0；并且 lr 1e-4 网络的远端底（|Δt| 30…38 均值）比被试低至少 10%。
- **不支持平衡版**：两个 lr 1e-4 网络的 g 都 > 0.5·g0（提升没有"明显变小"）。这时看远端底：底基本不变（变化 < 10%）与随机游走版和非噪声解释都相容，这次实验无法区分二者，论文里照此写明。
- 其余情况记为"结果不一致"，逐项报告。

### 我的预期（写下来以便事后对照，不影响判断规则）
我倾向于第 2 种：weight decay 在 2000 步里几乎不起作用，Adam 在 lr 1e-4 下每步的随机移动只有原来的 1/10，远端底大概不会明显下降；所以我预计 lr 1e-4 网络上 H1 仍有明显提升（猜 ≥ +0.25 pp），即**不支持平衡版**。lr 1e-3 继续训练的网络，远端底略升，H1 提升与被试相近或略大。把握不大（约六成）：如果远端权重确实受到损失函数的拉力（它们给隐藏单元加噪声，梯度期望会把它们往 0 推），平衡版也可能成立。

## 追加（2026-11-04 08:16 UTC，在看过 B1 预设网格的结果之后写）

B1 预设的 22 个设置全部是 0/28（结果见 `reading_baseline_generic_out.txt`），我对 G1 和 G3b 的预测落空。
诊断（只为解释，不算新方法）：每行第 1、2 近邻 99% 是同一特征的相邻时刻，第 3、4 近邻约 90%，第 5 近邻只有 4% 是 |Δt|≤2 的同特征行，15% 来自别的特征。所以 k ≥ 5 的 kNN 图是连通的，谱聚类切不开。

**追加的探索性设置（不在预设网格里，是看了结果之后加的，论文里会单独标出）**：G1 的 k ∈ {2, 3, 4}（两种分配方式，共 6 个设置），其他一切与 G1 相同。
注意：选 k = 2 本身就用到了 1B 的观察（"两强两弱"），所以即使成功，也不能算"不知道答案的通用方法"，只能说明"关键在于选对近邻尺度"。
预测：k = 2 时能恢复相当一部分（≥ 10/28），k = 3、4 时明显变差。
