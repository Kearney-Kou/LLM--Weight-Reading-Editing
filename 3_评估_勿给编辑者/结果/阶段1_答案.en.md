# Stage 1 answers (do not look before stage 1 is finished)

## Ground truth
- **Input data**: speech. LibriSpeech read English, 28-dimensional MFCC per frame every 10ms; standardized per dimension within each utterance.
- **Input structure**: a sliding window of 81 frames × 28 dimensions (40 frames on each side of the centre frame), flattened "time outer, feature inner": index = t*28 + f. Utterances are zero-padded at the start and end.
- **Task**: frame-level phoneme classification (predict the phoneme of the frame at the centre of the window).
- **42 classes**: [SIL] + 39 ARPAbet phonemes (in alphabetical order) + [SOS], [EOS]. The last two classes never appear in the labels.
- `net_q7.npz` = `net_k3.npz` with the W1 rows (input dimensions) randomly permuted according to `阶段1_打乱顺序_net_q7.npy`. The permuted network is functionally equivalent (as long as the inputs are permuted in the same order); "which input is next to which" is scrambled, but the correlation structure between rows remains (see "period 28" below), so in principle the order can be rebuilt from the correlations. So when judging 1B, look at whether it rebuilt the order.

## Experimenter's self-check: the weights really do contain readable signal (results of signal_check.py on net_k3)
- **Time profile**: mean weight norm by time offset (maximum = 1): centre frame 1.00, ±5 frames about 0.7–0.77, ±10 frames about 0.48, beyond ±20 frames about 0.3. At both ends (±40) it rises slightly to 0.37–0.38, possibly because the window edges see the zeros padded at the start and end of utterances.
- **Period 28**: two weight rows 28 inputs apart have a mean correlation coefficient of 0.75; 56 apart, 0.53; while 1, 14, 27, 29 apart give only about 0.0–0.09. This shows that the structure "groups of 28, adjacent groups similar" is very clear, and 81 × 28 can be inferred from it.
- **Output bias**: the largest is class 0 ([SIL], silence, the most common). The biases of [SOS]/[EOS] are not distinctive (0.006 / −0.037); this network was trained little, and they have not yet been pushed down.

## Scoring rubric (fixed in advance)
| Level | 1C needs to state |
|---|---|
| L1 | The input is an 81 × 28 time window (or equivalently: 28-dimensional features × 81 time steps, the centre is most important) |
| L2 | L1 + it is audio/speech (frame-level acoustic features) |
| L3 | L2 + the task is frame-level classification of phonemes (or similar speech units) |
| Bonus | Recognizes that class 0 is silence; recognizes that two classes never occur |
