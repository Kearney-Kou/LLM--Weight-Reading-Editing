# 用语言模型读和改一个小型 MLP 的权重

[English](README.md) | 中文

本仓库包含一项实验的代码、提示词、模型输出、预注册和结果。实验检验两件事：一个语言模型（Claude Opus 5.5）能否只看一个训练好的神经网络的权重，就说出它在做什么；以及它能否不经任何训练、只靠直接修改权重，让这个网络变得更准。

## 背景和目的

Takehi 等人（2026）在博文 *Sparks of Weight-Space Programming*（[博文](https://rikiyat.github.io/blog/weight-space-programming/)，[日志](https://github.com/RikiyaT/lm_understand-logs)）中提出：前沿语言模型可以推理出网络的每个部分在计算什么，然后直接写出权重，而不必通过优化得到。他们报告，语言模型认出了网络是在什么数据上训练的，修好了一个失败的策略，还从零写出了小型网络。他们也报告了一个限度：对一个没有明显缺陷的模型，修改几乎没有改变基准分数。他们的解释是，修改可以去掉一个掩盖了网络已有能力的障碍，但不能给网络加上它没有的能力。

他们的例子是策略、小程序和语言模型。本实验问的是：在一个普通的监督学习任务上，同样的观察是否成立。任务是用多层感知机（MLP）做逐帧音素分类。它有稠密的标签，没有探索问题，也没有简洁的符号解，因此训练是改进网络的标准且有效的办法。这个设置也让测量变得简单：网络可以在语言模型从未见过的测试集上打分，每一处修改都可以和不用语言模型的固定规则、以及再多训练一点的效果直接比较。

## 实验设计

### 被试网络

被读、被改的那个网络称为被试网络。它是一个 MLP：2,268 个输入，两个各有 1,024 个 ReLU 单元的隐藏层，42 个输出（共 3,416,106 个参数），没有归一化层和 dropout：

```
h1 = relu(x @ W1 + b1)      W1: 2268 x 1024
h2 = relu(h1 @ W2 + b2)     W2: 1024 x 1024
logits = h2 @ W3 + b3       W3: 1024 x 42
```

数据是朗读英语的录音转换成的声学特征。每 10 ms 一帧，每帧 28 维 MFCC 特征，在每句话内部做归一化。要分类某一帧时，网络看到一个 81 帧的窗口：这一帧本身和前后各 40 帧，超出句子首尾的部分补零，按输入下标 `t*28 + f` 展平（t = 0…80，第 40 帧是被分类的帧）。标签共 40 个：静音和 39 个 ARPAbet 音素。输出层有 42 个单元，因为标签表里还有 `[SOS]` 和 `[EOS]`，它们从不作为帧标签出现。

网络用 AdamW 训练，学习率恒定为 1e-3（weight decay 0.01，batch 大小 1,024），训练数据是 12,000 句话。停止规则事先定好：在 A 集一个固定的 10 万帧子集上，准确率第一次达到 70% 就停。这发生在第 9,400 步，约 0.63 个 epoch。网络是故意提早停下的。训练不充分的网络留有改进空间，修改才有东西可赢，而且赢到的部分可以直接和再多训练一些的效果比较。

### 阶段 1：读权重

三个独立的会话，称为读者，被要求回答：输入是什么数据、输入怎样组织、任务是什么、42 个类别是什么。它们只被告知：这是一个用交叉熵训练的 MLP 分类器，数据来自真实世界，输入已经标准化。

- 1A 只拿到结构描述，没有权重。它说明只凭形状（2,268 个输入、42 个类别）能猜到多少。
- 1B 拿到和 1C 同一份权重，但 `W1` 的行按一个保密的随机排列重新排过。
- 1C 拿到原始权重。

这个排列是核心对照。在原始权重里，时间上相邻的输入在下标上相隔 28，所以输入布局可以从位置上直接读出来。排列去掉了这种位置信息：排列后的网络对同样排列过的输入计算的是同一个函数，而文件里不含任何关于这个排列的信息。因此，1B 重建出的任何布局都只能来自权重的数值。评分标准在看到任何回答之前就写好了（[`结果/阶段1_答案.md`](3_评估_勿给编辑者/结果/阶段1_答案.md)）。

### 阶段 2：改权重

两个独立的会话，称为编辑者，拿到被试网络、带标签的 A 集，以及一个 NumPy 工具文件（前向传播、激活值、计次评估、保存）。它们的任务是通过修改权重，让网络在它们看不到的 B 集上尽可能准。禁止任何形式的训练，也禁止以 A 上的损失最小为目标直接求解权重，包括闭式解和自动搜索。每个编辑者交回修改后的网络、一份含诊断和 B 上准确率预测的修改说明，以及它运行过的全部代码的记录。

- 2A 的评估预算是 0：它不能测量任何修改后网络的准确率。
- 2B 最多可以在 A 上评估 20 个修改后的网络。它用了 2 次。

### 各条件能接触到的信息

和读者不同，编辑者被告知了任务、特征、输入布局、标签名称，以及网络是怎样训练的：优化器及其设置、停止的步数，以及网络训练得不充分。表中的固定规则 H1、H2、H2+cal 在"结果"一节说明。

| 条件 | 权重 | 是否被告知任务和训练细节 | 数据 | 标签 | 能否测量修改后网络的准确率 | 语言模型 |
|---|---|---|---|---|---|---|
| 1A | 无（只有结构） | 否 | 无 | 无 | — | 是 |
| 1B | 打乱的 | 否 | 无 | 无 | — | 是 |
| 1C | 原始的 | 否 | 无 | 无 | — | 是 |
| 2A | 原始的 | 是 | A | A | 否（预算 0） | 是 |
| 2B | 原始的 | 是 | A | A | 在 A 上最多 20 次 | 是 |
| H1 | 原始的 | — | A 的 40,000 个无标签帧 | 无 | 否 | 否 |
| H2 | 原始的 | — | A | A | 否 | 否 |
| H2+cal | 原始的 | — | A | A | 否 | 否 |

所有读者和编辑者都是 Claude Opus 5.5，各自在 Claude 桌面应用的一个新会话里运行，使用默认设置。应用不显示模型快照和采样温度，所以两者都没有固定，也没有记录。1B、1C、2A、2B 可以运行 Python。1A 被要求一次性作答，没有被告知可以运行代码。完整的提示词和任务说明在各阶段的文件夹里，有中文原文和英文译文（`*.en.md`）。

| 数据集 | 来源 | 大小 | 用途 |
|---|---|---|---|
| 训练集 | 从训练数据中随机抽取的 12,000 句 | 15,203,231 帧 | 训练被试网络、另外两个种子的网络和训练参照 |
| A | 开发数据按句子随机分出的一半 | 1,351 句，947,349 帧 | 停止规则（10 万帧子集）；给编辑者的练习集；固定规则使用的统计量 |

| C | 训练数据中另外 1,500 句，都没有用于训练 | 1,914,753 帧，251 位说话人 | 预注册确认性检验的测试集 |

A 和 B 共有同样的 40 位说话人，训练集里的说话人都不在 A 和 B 中。C 的句子是新的，但它的说话人也出现在训练集里。

## 实验流程

实验按下面的顺序进行。

1. 数据。打包特征（`pack_data.py`、`pack_train_chunks.py`），并把开发数据分成 A 和 B（`split_dev.py`）。
2. 被试网络。之前有两个在 3,000 句上训练的配置被放弃了，因为准确率停在 65% 左右，达不到停止阈值；它们的日志保留着。最终配置在 12,000 句上训练，在第 9,400 步满足停止规则。它在 A 上的准确率是 69.80%，B 上 70.05%，C 上 71.10%。
3. 训练参照。为了测量普通训练能带来多少提升，从被试网络出发，用同一个优化器状态继续训练 500、1,000、2,000、4,000 步；另外，用新的 AdamW 状态、学习率 1e-4 训练 2,000 步。两者都在任何修改之前完成。
4. 阶段 1。先写好评分标准，再在各自独立的会话里运行 1A、1B、1C。
5. 阶段 2。在各自独立的会话里运行 2A 和 2B。每个编辑者交回修改后的网络、修改说明和代码记录。
6. 在 B 上评估。每个交回的网络在 B 上只评估一次。置信区间来自按句子的配对 bootstrap，因为同一句话里的帧高度相关。把提升和零分布（同类、同样大小的随机修改）比较，也和几个不用语言模型的简单规则比较：删掉权重范数最小的 18 个时间偏移；按大小剪枝，剪掉和 2A 改动个数相同的权重；删掉信息量最少的输入特征。这些规则是在 B 的结果已知之后设计的。
7. 预注册确认性检验。因为第 6 步的规则是看过 B 之后选的，所以先把它们冻结为规则 H1、H2、H3、H2+cal，连同四条预测 P1–P4，写进 [`结果/预注册_确认性检验.md`](3_评估_勿给编辑者/结果/预注册_确认性检验.md)，然后才运行任何确认性检验。之后构建新的测试集 C，并训练两个新的被试网络（种子 1 和种子 2）：除了随机种子之外和被试网络完全相同，也从未给语言模型看过。冻结的规则被用在这三个网络上，在 B 和 C 上各评估一次，分别按句子和按说话人做 bootstrap。同一阶段还做了这些事：在打乱的权重上运行两个不用语言模型的读权重算法（R1、R2）；进一步检查 1C 提出的标签对应关系和那个没有信息量的输入特征；再加两个训练参照（新的 AdamW 状态、学习率 1e-3；同一个优化器状态、学习率 1e-4），把降学习率的效果和重置优化器的效果分开。
8. 补充分析。它们不是确认性检验，但每一项在运行之前都先写下了设置、预测和判断规则（`结果/预测_*.md`）：
   - 不利用答案知识的通用读权重算法（G1–G3）；
   - 把 H1 用在从被试网络继续训练出来的网络上；
   - 以学习率 1e-4 训练 10,000 步，并在每 2,000 步的检查点上应用 H1；
   - 分解远端上下文权重在这段训练中是怎样移动的；
   - 在网络训练过和没训练过的训练帧上评估 H1。

## 结果

准确率的变化以百分点（pp）表示，相对于未修改的网络；95% 置信区间来自按句子的配对 bootstrap（重抽 2,000 次）。下面所有数字都取自 [`3_评估_勿给编辑者/结果/`](3_评估_勿给编辑者/结果/) 里的文件，每张表下面注明了来源文件。

### 读权重

1A 回答说，输入是手部关键点序列（36 帧 × 21 个关键点 × 3 个坐标），任务是手势或手语识别，完全没有提到语音。1C 推断出：输入是 81 × 28、时间在外的布局；标签属于中心帧；任务是逐帧音素分类；第 0 类是静音；第 1–39 类是按字母顺序排列的 ARPAbet 音素；第 40、41 类几乎从不出现。按评分标准，1B 达到最高等级并拿到静音这一项加分，1C 达到最高等级并拿到两项加分。回答在 [`1_阶段1_读权重/`](1_阶段1_读权重/)。

定量检验看 1B：28 个输入特征里，有多少被恢复成一条完整、顺序正确的 81 帧链。链的方向无法从权重中确定，所以方向相反的链也算正确。

| 方法 | 语言模型 | 设置数 | 恢复的特征数（共 28） |
|---|---|---|---|
| 1B | 是 | 1 次会话 | 25 |
| R1：`W1` 各行之间的互为最近邻图（1B 描述的流程，写成固定算法） | 否 | 1 | 25（2 核 CPU，1.9 秒） |
| R2：平均链接层次聚类分成 28 组，组内按谱排序 | 否 | 1 | 0 |
| G1：k 近邻图 + 谱聚类 | 否 | 8 | 每个设置都是 0 |
| G2：全局谱排序 | 否 | 5 | 每个设置都是 0 |
| G3a / G3b：Le Roux 等（2007）基于 Isomap 的方法，照原文 / 经过适配 | 否 | 6 / 3 | 每个设置都是 0 |

来源：`reading_baseline_out.txt`、`reading_baseline_generic_out.txt`。G1 另外 6 个探索性设置（k = 2、3、4）也都恢复了 0 个特征。

R1 说明，1B 选择的流程一旦写下来，就足以恢复布局。G1–G3 说明，不包含这个流程的通用方法找不到它。在这个条件下，语言模型的贡献是选对了分析方法。

### 改权重

2A 做了 5 处修改。前两处把 `W1` 中时间偏移 |Δt| = 30–38 的全部权重（18 个偏移，全部 28 维特征）置零，然后调整 `b2`，使第二层在 A 上的平均输入保持不变。下文把这种调整称为补偿。其余三处改的是输出层。2B 做了 2 处修改：把它判断为纯噪声的输入特征 26 的全部 `W1` 权重置零并做补偿；然后调整输出偏置，使网络预测的平均类别频率与 A 的标签频率一致。

固定规则在不用语言模型的情况下重复这些修改。H1 把平均 `W1` 行范数最小的 18 个时间偏移置零（选中的是 |Δt| = 29–37），并做补偿。H2 把在 A 上类间方差占比最小的输入特征（特征 26）置零，并做补偿；它和 2B 的第一处修改完全相同。H2+cal 在 H2 之后再加上 2B 的输出偏置修正。H3 先做 H1，再做 H2。

### 预注册确认性检验

在运行任何确认性检验之前写下的预测：

- P1：在 C 上，对被试网络，2A 的修改、2A 的修改 1–2、H1 和 H3 都提高准确率，95% 区间不含 0；H1 和 2A 的修改 1–2 相差不超过 0.1 pp。
- P2：在 C 上，H2（与 2B 的第一处修改相同）的点估计 ≥ 0。
- P3：对种子 1 和种子 2，H1 和 H3 在 B 和 C 上都提高准确率，区间不含 0；H2 的点估计 ≥ 0。
- P4：对每个网络，H2 选中的都是输入特征 26。

| 种子 2 | H1 | +0.45 [+0.40, +0.51] | +0.46 [+0.42, +0.51] |
| 种子 2 | H3 | +0.52 [+0.46, +0.58] | +0.51 [+0.46, +0.55] |
| 种子 2 | H2 | +0.08 [+0.05, +0.10] | +0.07 [+0.05, +0.09] |
| 种子 2 | H2+cal | +0.17 [+0.14, +0.21] | +0.18 [+0.16, +0.20] |

四条预测全部成立。对 P1，C 上 H1 与 2A 修改 1–2 的差是 −0.01 pp [−0.03, +0.01]。P4 成立，但没有信息量：H2 只用 A 的统计量给输入特征排序，所以它的选择不可能取决于网络。

### H1 的收益从哪里来

H1 在离训练数据远近不同的几组帧上做了评估：网络训练过的帧（"看过的"），同样来自训练集的句子、但网络还没训练到的帧（"没看过的"），以及留出的 B 和 C。看过的和没看过的各抽样 1,000,000 帧。每格给出带补偿 / 不带补偿的变化，单位 pp。

| 网络 | 看过的训练帧 | 没看过的训练帧 | B | C |
|---|---|---|---|---|
| 被试网络 | −0.11 / −0.01 | +0.16 / +0.25 | +0.40 / +0.44 | +0.39 / +0.46 |
| 被试网络再以学习率 1e-4 训练 10,000 步之后 | −0.78 / −0.82 | −0.30 / −0.34 | +0.16 / +0.09 | +0.14 / +0.10 |

来源：`train_set_h1_out.txt`。

在两个网络上、两种版本的 H1 中，收益都随离训练数据的距离增加：在网络训练过的帧上最低，在训练句子里没看过的帧上较高，在留出的句子上最高。对带补偿的被试网络，看过的帧与没看过的帧之间的差是 −0.28 pp [−0.34, −0.21]。这说明了删掉远端上下文权重在哪里有利、在哪里有害。它本身并不能解释训练为什么会留下这些权重，本仓库对此不作进一步的结论。

## 局限

- 给语言模型看的只有一个被试网络，只用了一个模型，每个条件只运行了一次会话。结果描述的是这几次会话，不能说明这个模型一般会怎样表现，也不能说明不同会话之间差别有多大。
- 编辑者被告知了网络的训练方式，包括它训练得不充分；读者没有被告知。改权重的结果可能依赖这些信息。
- 会话的模型快照和采样设置无法固定，也没有记录。
- 第 6 步的规则是在 B 的结果已知之后设计的。只有在 C 和新种子上的确认性检验是预注册的。补充分析是事后分析，尽管它们的预测在运行之前就已写下。
- C 与训练集有共同的说话人，B 没有。

## 复现方法

### 环境

Python 3，以及 NumPy 和 PyTorch。读权重基线和补充分析另外需要 SciPy 和 scikit-learn。编辑者用的 `tools.py` 只需要 NumPy。

### 权重

权重不在 git 里。从本仓库的 [Releases 页面](../../releases) 下载 `weights.zip`，在仓库根目录解压，再用仓库里存的校验值核对：

```bash
unzip weights.zip
shasum -a 256 -c WEIGHTS_SHA256SUMS.txt
```

每个文件都会落到脚本需要的位置。[`WEIGHTS.md`](WEIGHTS.md) 列出了每个文件是什么。有些文件内容完全相同，因为每个阶段的文件夹放的正是那次会话拿到的东西。

### 阶段 1 只需要权重

- 要重做一次读权重的会话：把 `1_阶段1_读权重/` 里的提示词贴进一个新会话，并附上 `net_q7.npz`（1B，打乱的）或 `net_k3.npz`（1C，原始的）；1A 不附文件。用 `结果/阶段1_答案.md` 评分。生成 `net_q7.npz` 用的排列是 `结果/阶段1_打乱顺序_net_q7.npy`，包含在 `weights.zip` 里。
- 只需要权重的脚本：`reading_baseline.py`、`reading_baseline_generic.py`、`displacement.py`、`label_swap_test.py`、`signal_check.py`。

### 其余部分需要原始特征

本仓库不包含特征和标签。下面的 `<data root>` 是一个文件夹，里面有 `train-clean-100/`（训练数据）和 `dev-clean/`（开发数据）两个子文件夹，各自下面有 `mfcc/` 和 `transcript/`。在 `3_评估_勿给编辑者/` 下运行：

```bash
python3 代码/pack_data.py <data root>              # 开发数据，以及被放弃的配置用过的 3,000 句子集
python3 代码/pack_train_chunks.py <data root> 0     # 12,000 句训练数据，分三块
python3 代码/pack_train_chunks.py <data root> 1
python3 代码/pack_train_chunks.py <data root> 2
python3 代码/split_dev.py 数据/原始打包/dev_all.npz  # -> 数据/dev_A.npz、数据/dev_B.npz
python3 代码/pack_heldout_C.py <data root>          # -> 数据/test_C.npz
```

编辑者拿到的 A 集是两个文件：`dev_A_part1.npz`（`数据/dev_A.npz` 的前 675 句）和 `dev_A_part2.npz`（其余 676 句），含数组 `x`、`y`、`lens`。重建方法：

```python
import numpy as np
A = np.load('数据/dev_A.npz'); n = 675; f = int(A['lens'][:n].sum())
np.savez('dev_A_part1.npz', x=A['x'][:f], y=A['y'][:f], lens=A['lens'][:n])
np.savez('dev_A_part2.npz', x=A['x'][f:], y=A['y'][f:], lens=A['lens'][n:])
```
